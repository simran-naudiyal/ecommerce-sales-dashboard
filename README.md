## 📝 Project Overview
An executive-level interactive Power BI dashboard designed to monitor and evaluate an e-commerce business's key performance indicators (KPIs). This solution transforms raw transaction metrics into operational insights, focusing on sales trends, geographical performance, and product profitability.

## 📈 Key Dashboard Focus Areas & Analytics
* **Sales Performance Tracking:** Real-time visibility into overall revenue, profit margins, and total order volume.
* **Customer Insights:** Breakdown of customer segments and preferred payment methods.
* **Geographical & Category Deep-Dive:** Identification of top-performing sales regions and product categories driving core business growth.

## 🛠️ Data Modeling & Design Features
* **Modern Executive UI/UX:** Built using high-contrast layouts and sharp visualization hierarchies for executive-level scanning.
* **Star Schema Data Model:** Structured with separate fact and dimension tables to optimize model performance and query speeds.
* **Advanced DAX Formulas:** Developed custom measures using specialized functions (`CALCULATE`, `DIVIDE`, and time-intelligence expressions) to extract dynamic business intelligence.
